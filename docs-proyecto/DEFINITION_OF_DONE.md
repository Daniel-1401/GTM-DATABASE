# Estado documental — GTM Database

Este archivo se conserva como punto de compatibilidad para el lineamiento del
núcleo. El detalle operativo vive únicamente en los documentos vigentes:

- `requirements.md`: alcance y decisiones del núcleo.
- `STACK.md`: stack y límites aprobados.
- `er-diagram-v1.md`: modelo conceptual del núcleo.
- `er-diagram-fisico-v1.md`: modelo físico del núcleo.
- `er-diagram-fisico-alimentacion-v1.md`: modelo físico de Alimentación.
- `CONTRATO_STORES_BACKEND_ALIMENTACION.md`: catálogo de tablas y objetos
  programables pendientes de definición.
- `db-scripts-log.md`: trazabilidad de migraciones y reversión.
- `ESTADO_OFICIAL_OBJETOS_DB.md`: fuente de verdad sobre tablas oficiales y
  objetos no definidos.

No existe evidencia de ejecución contra SQL Server en este repositorio. La
implementación de endpoints u objetos programables requiere definición,
checkpoint y aprobaciones correspondientes.
